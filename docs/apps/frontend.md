# frontend

The "puus" suite — small self-hosted privacy frontends, all app-template, all on
port 3000 unless noted. **All eight use `className: external`** → they are
publicly reachable through Cloudflare with **no authentication**. Treat this
namespace as "public, no-auth by design" (or lock them down).

| App | Image | Notes |
|-----|-------|-------|
| breezewiki | `quay.io/pussthecatorg/breezewiki:latest` | Personal markdown wiki (SQLite). Config via `breezewiki-config` ConfigMap → `/app/config.ini`. ⚠ checked-in `config.ini` says `port=10416` (stale; service/probe use 3000). |
| librarian | `quay.io/pussthecatorg/librarian:latest` | BibTeX / bibliographic library manager. Plain single container, no persistence. |
| libreddit | `docker.io/tagliasteel/redlib` (untagged → latest) | Private Reddit frontend (Redlib fork; `LIBREDDIT_DEFAULT_SHOW_NSFW=true`). Most hardened app here: `readOnlyRootFilesystem`, caps drop ALL, 128Mi limit, `/settings` probes, `runAs 568`. Hajimari `reddit` icon. |
| libremdb | `ghcr.io/zyachel/libremdb:v4.5.0` | Personal movie/TV ratings DB. Only app pinned to an explicit tag. |
| priviblur | `quay.io/pussthecatorg/priviblur:latest` | Privacy status dashboard. Config via `priviblur-config` → `/priviblur/config.toml`. ⚠ ConfigMap data key is `config.ini` while the mount subPath is `config.toml` — mismatch (mount will be empty until fixed). |
| quetre | `quay.io/pussthecatorg/quetre:latest` | Q&A board (Quora-style). No persistence. |
| rimgo | `quay.io/pussthecatorg/rimgo:latest` | Image hosting/sharing. Probes/limits/securityContext are **commented out** in its HR (weaker than the rest of the suite). |
| scribe | `quay.io/pussthecatorg/scribe:latest` | Collaborative markdown editor. Probes/limits/securityContext also **commented out**. |

Most of this namespace comes from the upstream template's community add-on set
(`bootstrap/templates/kubernetes/apps/frontend/…j2`) — they're regenerated by
`task configure`, so keep changes in the bootstrap templates if you want them to
survive.
